## 🎬 What is This?

**CapCut EditFlow** is a desktop production assistant for video creators. It streamlines the boring parts of editing — organizing footage, managing assets, tracking versions, and keeping projects consistent — so you can spend more time on the creative work.

The suite runs independently as a helper application and never touches your editing software's files.
